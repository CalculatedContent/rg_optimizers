# MAGIC scale-invariant MLP
Independent positive radial reparameterization of each raw matrix, with trainable scalar gains initialized to match ordinary effective weights in the construction dtype. FP64 validation builds directly in FP64 rather than converting an FP32 gain. Biases unchanged. No weight decay, no spectral penalty, no dropout. Same original immutable data/splits, batch 256, clip 1, constant LR, fixed 20k updates. Four SGDM and three AdamW configurations, 2 development seeds each, then 5 confirmation seeds per validation-selected optimizer winner. 24 total runs maximum, 480k updates, five workers maximum. Test only at final confirmation endpoint; the reused test is exploratory.
Raw FC2 WW fit is unchanged from original; report effective spectral scale, gains and norms, fixed training-probe radial residual and last actual preclip minibatch residual at checkpoints. Last-update gradients refer to the preceding weights, not post-update checkpoint weights. Nominal LR/norm² is not actual Adam or momentum angular step. Scale invariance of the function does not establish volume preservation or alpha=2. Compare with ordinary controls in original and accelerated archives. All results permanently archived, including partial failures. No replay.
