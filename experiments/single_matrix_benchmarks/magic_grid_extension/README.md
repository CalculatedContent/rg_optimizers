# MAGIC expanded fixed-20k validation grid

User-authorized search extension, separate from original cohort. Original training/test results are unchanged. The new workflow is staged but inert until the primary MAGIC run 45831716594 is terminal and its 39-run archive is verified. Pin that exact archive commit by replacing both `__PRIMARY_ARCHIVE_COMMIT__` placeholders in the template; install once at `.github/workflows/single-matrix-magic-grid-extension.yml`. No other active training cohort. Never retry completed or partially trained jobs.

Original 12 configurations × 2 paired seeds are reused, not retrained. New six SGDM and six AdamW configurations × two same development seeds = 24 fresh jobs, at most 480,000 additional neural updates. Hard cap 20k per run, no dropout, same 10→784→784→2 architecture and prepared train/validation split, same batch size, clipping, seed and ordinary WeightWatcher FC2 fit. No new test access; no new confirmation training because the original held-out results have already been inspected.

SGDM additional (LR,momentum): (.0003,.90),(.001,.90),(.002,.90),(.001,.80),(.001,.95),(.003,.95). AdamW new LRs .00001,.00003,.00006 for each of WD=0 and WD=.001. All original winners lay at lower LR boundary. No duplicate cases.

Track accuracy, cross-entropy, ROC-AUC, gamma acceptance at fixed hadron FPR, train–validation gaps, binary Brier, ECE (15 equal-width bins), mean maximum softmax confidence, confidence of correct/incorrect predictions, fraction highly confident and fraction confidently wrong (threshold .90), and raw FC2 alpha, KS D and fitted tail size. Re-evaluate original 24 archived endpoint checkpoints for calibration using only train and validation, checking their archived weight hashes and prior metrics; no replay training. For new runs calibration at all six scheduled checkpoints. Report separate validation accuracy and CE winners, Pareto frontiers and all individual points; never select by alpha, test or calibration. Per-setting nominal two-seed t 95% intervals (df=1) are descriptive and wide; original five-seed confirmation remains separate, and independent confirmation would require a new authorization and fresh holdout. This extension is validation-only, not a new final test benchmark.

Run `python run.py` for the dry-run plan. Full workflow verifies primary archive, compiles, audits old endpoints before new training, archives complete or partial records, and creates tables, metrics and plots.
