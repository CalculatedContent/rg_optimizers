# Design review — 16 November 2026

| Primary source | Relevant evidence | Design implication |
|---|---|---|
| [Official Fashion-MNIST repository](https://github.com/zalandoresearch/fashion-mnist) | Community benchmark lists an unaugmented 256–128–100 MLP at 88.33% test accuracy. | The earlier high-80s MLP results are in a plausible range. This entry is neither an optimality guarantee nor a matched comparison. |
| [Kao and Hariharan, NeurIPS 2024, Counter-Current Learning](https://proceedings.neurips.cc/paper_files/paper/2024/file/82f05a105c928c10706213952bf0c8b7-Paper-Conference.pdf) | Table1 reports backpropagation Fashion-MNIST accuracy 89.58±0.25. Their MLP has six 256-unit layers, tanh, normalized inputs, 100 epochs and five seeds. | A published dense-network reference; architecture, activation and protocol differ from ours. CNN results in the paper are not a target for this MLP. |
| [Fashion-MNIST MLP implementation](https://github.com/hinata-koizumi/fashion-mnist-mlp/blob/main/README.md) | A public NumPy MLP implementation uses zero-padded translations up to two pixels, among several other techniques. | Implementation precedent, not a peer-reviewed guarantee. We use only a fixed mild translation recipe, identically paired across arms; no ensemble, test augmentation, dropout, smoothing or best-checkpoint selection. |
| [WeightWatcher changelog and source](https://github.com/CalculatedContent/WeightWatcher/blob/master/Changelog.txt) | Small-N estimator introduced in0.7.6. Pinned0.7.7 source includes n−1 correction, minimum8 tail values, and a cutoff objective with optional alpha prior defaulting to zero. | Report FC3 using the zero-prior small-N routine; preserve native-constructor alpha alongside it. Our audit found that the constructor reselects by KS after the routine selects by J, so the direct routine result is explicitly named. |
| [van Laarhoven, 2017](https://arxiv.org/abs/1706.05350) | Normalization changes the relationship between weight scale, regularization and effective learning rate. | Write the exact transformation and premise, rather than using “scale invariant” as a blanket label. See SCALE_DERIVATION.md. |

The new pass holds the dense architecture and optimizer kernel fixed, uses the original MNIST-length 120-epoch schedule, and introduces one common mild augmentation. It tests a single defensible configuration rather than claiming globally optimal performance. Width changes, layer ablations and further tuning require separate recorded follow-ups. Performance is assessed by accuracy and cross-entropy separately; all alpha and failure outcomes are retained.
