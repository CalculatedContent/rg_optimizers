# Experimental results

This directory is reserved for downloaded results of the stock GPT-2/FineWeb
MuonClip/AdamW experiment. It contains no measured results yet. Generated outputs
are ignored by Git; retain the verified cloud backup as the durable full record.

Copy each TPU `runs/<run-id>/` or `suites/<suite-id>/` hierarchy here intact.
Do not combine historical six-head runs with this experiment. Keep `commit.txt`,
`launch.json`, `manifest.json`, `MODEL_PREFLIGHT.json`, `RUN_STATUS.json`,
`metrics.jsonl`, `tracking/`, and `CLOUD_BACKUP_VERIFIED.json` alongside results.
The parent README defines the disk and cloud locations and completion criteria.
